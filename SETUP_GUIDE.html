מדריך התקנה טכני - בוט החשבוניות D-Dialog

מיועד עבור: עופר (Ofer) לצורך ביצוע התקנה והטמעה מלאה במחשב של שחף מיכאל.

דרישות קדם והתקנת סביבה

1 התקנת Python: ודא שמותקן Python 3.9 ומעלה (מומלץ 3.11 או 3.12).
חשוב מאוד: במהלך התקנת ה-Installer של פייתון בווינדוס, יש לסמן ב-V את התיבה "Add Python to PATH".
2 התקנת חבילות קוד (Dependencies): פתח את ה-CMD בתיקיית הפרויקט המקורית והרצ:
pip install -r requirements.txt
החבילות העיקריות המותקנות: google-api-python-client, google-auth-oauthlib, google-genai, reportlab, pydantic.

הגדרת פרויקט Google Cloud (עבור שחף)

יש ליצור פרויקט גישה ייעודי כדי לקבל את קובץ הרישיון המקורי:

  1. היכנס ל- Google Cloud Console באמצעות חשבון הגוגל של שחף.
  2. צור פרויקט חדש בשם Shachaf-Invoice-Bot.
  3. עבור ל-APIs & Services -> Library והפעל (Enable) את שלושת ה-APIs הבאים:
    • Gmail API
    • Google Drive API
    • Google Sheets API
  4. עבור ל-OAuth consent screen:
    • בחר ב-External ולחץ על Create.
    • מלא את פרטי האפליקציה (שם, מייל תמיכה ומייל מפתח - כולם של שחף).
    • בשלב ה-Scopes, לחץ על Add Scopes והוסף ידנית את הגישות הבאות:
      https://www.googleapis.com/auth/gmail.readonly (לקריאת מיילים)
      https://www.googleapis.com/auth/gmail.send (לשליחת מייל הסיכום בסיום)
      https://www.googleapis.com/auth/drive (ליצירה ועריכת קבצים ותיקיות בדרייב)
    • בשלב ה-Test Users, לחץ על Add Users והוסף את כתובת הג'ימייל של שחף (המייל שייסרק).
  5. עבור ללשונית Credentials:
    • לחץ על Create Credentials ובחר ב-OAuth client ID.
    • בחר בסוג אפליקציה: Desktop Application.
    • הורד את קובץ ה-JSON שנוצר (Download JSON).
    • שמור את הקובץ בתיקיית הבוט ושנה את שמו ל-credentials.json.

הגדרת Gemini AI והגדרות פנימיות

  1. היכנס ל- Google AI Studio בחשבון של שחף.
  2. לחץ על Get API key וצור מפתח API חדש.
  3. פתח את הקובץ config.py בתיקיית הבוט והזן את הערכים הבאים:
    • GEMINI_API_KEY = 'הכנס_את_המפתח_של_שחף_כאן'
    • NOTIFICATION_EMAIL_RECIPIENT = 'מייל_היעד_של_שחף_לקבלת_דוחות' (אם יישאר ריק, הבוט ישלח אוטומטית למייל המחובר של שחף עצמו).
    • PARENT_FOLDER_ID = '' (אם ברצונך שכל תיקיות החשבוניות והאקסלים החודשיים ייווצרו בתוך תיקיית-על ספציפית בדרייב שלו, צור תיקייה בדרייב שלו, העתק את ה-ID שלה מכתובת ה-URL והדבק אותו כאן. אם יישאר ריק, התיקיות ייווצרו בתיקיית השורש של הדרייב).

אימות ראשוני (Authentication Run)

שים לב: הריצה הראשונה חייבת להתבצע באופן ידני כדי לבצע את ה-OAuth flow בדפדפן.
  1. הרצ את הקובץ Run_Bot.bat (או הרצ ב-CMD: python main.py).
  2. ייפתח דפדפן במחשב שיבקש להתחבר לחשבון הגוגל של שחף.
  3. מכיוון שהאפליקציה בשלבי פיתוח (Testing), גוגל יציג אזהרה שהאפליקציה אינה מאומתת. יש ללחוץ על Advanced (מתקדם) ואז על Go to App (unsafe).
  4. אשר את הרשאות הגישה.
  5. בסיום, הבוט יפעל ובתיקיית הבוט ייווצר קובץ קריטי בשם token.json. קובץ זה מכיל את הרישיון המקומי של שחף ומאפשר לבוט לרוץ מאותו רגע באופן עצמאי לחלוטין ללא שום צורך באישור דפדפן נוסף.

הגדרת ריצה אוטומטית (Task Scheduler - מתזמן המשימות)

כדי שהבוט יפעל לבד ברקע בכל 1 לחודש וישלח לשחף דוח אוטומטי של החשבוניות של החודש החולף:

  1. פתח את Task Scheduler בווינדוס של שחף.
  2. לחץ על Create Basic Task.
  3. תן שם למשימה (לדוגמה: D-Dialog Invoice Bot) ולחץ על Next.
  4. בחר ב-Trigger: Monthly.
  5. הגדר את המשימה לפעול ביום ה-1 בכל חודש, בשעה מוקדמת (לדוגמה: 08:00 בבוקר).
  6. ב-Action, בחר ב-Start a program.
  7. ב-Program/script לחץ על Browse ובחר בקובץ Run_Bot.bat בתיקיית הבוט.
  8. שלב קריטי: בשדה Start in (optional), העתק והדבק את הנתיב המלא של תיקיית הבוט (לדוגמה: C:\Users\Shachaf\Desktop\shachaf_m).
    אם לא תגדיר שדה זה, הבוט יקרוס בריצה הרקעית כי הוא לא ידע היכן למצוא את קובץ credentials.json והספריות.
  9. לחץ על Finish. המערכת מוגדרת ואוטומטית לחלוטין!
